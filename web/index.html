How this works — plain-language explainer

What is a Raven?

A small program that watches one news source — like a website's RSS feed — on a timer. It never sleeps: it wakes up every so often (say, every 30 minutes), checks for new stories, and goes back to waiting. One Raven only ever watches one source. If you want to watch five sources, you run five Ravens.

Topic and Target — the two things a Raven needs

Topic is the word or phrase it's listening for — "AI", "climate", "central bank." Target is the source it's watching — a name (like "BBC News") and the actual feed address (a URL ending in something like /rss or /feed). A Raven only cares about stories where its Target published something matching its Topic.

What happens when it finds a match

Raven checks the feed→ headline matches Topic?→ fetches the full article→ sends it to Feather→ Feather reviews & stores it

The Raven itself does no thinking — it's a dumb, reliable fetch-and-match loop on purpose. Feather's own analyzer is what actually reads the article afterward (with safeguards, since scraped web pages are not trustworthy input — more on that below).

How it keeps running

Each Raven is installed as a systemd service — a standard piece of Linux that starts programs automatically when the server boots, and restarts them if they ever crash. You never have to remember to start a Raven by hand; once it's installed and enabled, it just runs, forever, quietly, in the background.

A note on safety

Article text pulled in by a Raven is treated as untrusted the moment it lands on Feather's side — a scraped web page can contain text deliberately written to trick an AI reading it (a real example showed up in testing: a "news" page that tried to instruct an AI to install a data-exfiltrating browser connector). Feather's analyzer screens for that before any of it reaches a model. This page and the Raven itself don't run any AI at all, so there's nothing here for that kind of trick to target.
